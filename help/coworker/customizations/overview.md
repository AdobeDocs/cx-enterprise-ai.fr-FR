# Présentation des personnalisations des collègues {#overview}

Les personnalisations vous permettent d’étendre et de personnaliser Coworker pour l’adapter au fonctionnement de votre équipe. Utilisez les compétences pour normaliser les workflows répétables, les intégrations pour connecter Coworker à vos autres systèmes, les plug-ins pour regrouper les fonctionnalités associées dans un package installable et la mémoire pour transmettre vos préférences et votre style de travail entre les conversations.
