# Gestion des plug-ins et des places de marché dans [!DNL CX Enterprise Coworker Chat]

Découvrez comment les administrateurs peuvent étendre le Chat des collaborateurs Adobe avec des plug-ins approuvés, gérer les places de marché et régir l’accès aux compétences et aux outils connectés tout en conservant l’alignement avec les autorisations Adobe existantes.

>[!VIDEO](https://video.tv.adobe.com/v/3504182/?learn=on&enablevpops)

## Ce que vous apprendrez
 
Dans cette vidéo, vous découvrirez comment fonctionne la gestion des modules externes dans Adobe Coworker et comment les administrateurs peuvent introduire en toute sécurité de nouvelles fonctionnalités pour leurs équipes.
 
Vous apprendrez :
 
- La différence entre les marchés, les plug-ins, les compétences et les serveurs MCP
- Comment les plug-ins conditionnent les compétences et les services connectés à utiliser dans Coworker
- Pourquoi les autorisations de produit et les profils de produit Adobe déterminent l’accès aux fonctionnalités
- Comment Coworker hérite automatiquement des autorisations des produits Adobe connectés
- Pourquoi la validation de votre organisation Experience Cloud et du sandbox Experience Platform est une étape administrative importante
- Navigation dans la zone Personnalisations de Coworker
- Comment ajouter un nouveau marketplace à l’aide d’un référentiel GitHub
- Installation et gestion des modules externes pour votre organisation
- Comment vérifier les compétences incluses dans un plug-in avant le déploiement
- Comment déterminer si les utilisateurs peuvent installer ou supprimer eux-mêmes des modules externes
- Éléments à prendre en compte avant de supprimer un plug-in de votre environnement
- Comment les utilisateurs peuvent-ils personnaliser leur propre espace de travail dans les limites définies par l’administrateur ?
